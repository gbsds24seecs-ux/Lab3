# Gulwarina Muska Saleem - Personal Portfolio

This portfolio was created for Web Engineering Lab 4. It extends the previous HTML portfolio by organizing the project into folders, using an external CSS stylesheet, applying `float` and `clear`, and preparing the website for GitHub Pages deployment.

## Project Structure

```text
portfolio/
├── index.html
├── hobbies.html
├── contact.html
├── gallery.html
├── skills.html
├── css/
│   └── style.css
├── images/
│   ├── 1.png
│   ├── 2.png
│   ├── 3.png
│   ├── 4.png
│   ├── 5.png
│   └── myphoto.jpg
└── README.md
```

## Lab Requirements Covered

- External CSS stylesheet linked to all HTML pages
- Horizontal navigation menu styled with CSS
- `float` and `clear` used for layout
- Image gallery containing five images arranged using `float`
- Images placed in an `images/` folder
- CSS placed in a `css/` folder
- No JavaScript used
- No CSS framework or API used
